If you already have the **EngiSummary frontend project**, run it like this in VS Code:

### 1. Open the frontend folder

```bash
cd path\to\EngiSummary\frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

You should see something like:

```text
Local: http://localhost:5173/
```

Open that URL in your browser.

### If `npm` is not recognized

Check Node.js:

```bash
node -v
npm -v
```

If both don't work, install **Node.js** first.

### If you have `.env.example`

Create a `.env` file:

```env
VITE_API_BASE_URL=http://localhost:8000
VITE_MOCK_MODE=true
```

For now, keep `VITE_MOCK_MODE=true` so the frontend works **without your backend**.

### For production build

```bash
npm run build
```

Then preview it:

```bash
npm run preview
```

**For your current project, the main command you need is:**

```bash
npm install
npm run dev
```
